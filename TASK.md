## Decisions
- Fresh repo `masjid-records-v2`, stack = React + TS + Vite + Tailwind.
- Deploy via GitHub Actions to Pages (build_type=workflow set 2026-11-12).
- Routing = HashRouter (safe on Pages). Vite base = `/masjid-records-v2/`.
- Design = Sanctum: azure #0E5C86/#4E9BC7, Sora display + Manrope body, white cards r20, bg #F5F7F9.
- Hero photo = Wikimedia Commons (Sultan Ahmed Mosque), public/hero.jpg.
- Auth = client-side accounts, SHA-256 hashed passwords, roles owner/user,
  12h session, 5-try / 5-min login lockout. Owner-only screens via `RequireOwner`.
- Persistence = localStorage stores + `useSyncExternalStore` hooks. Keys:
  `mkr_families_v2`, `mkr_settings_v2`, `mkr_accounts_v2`, `mkr_session_v2`,
  `mkr_audit_v2`, `mkr_notices_v2`, `mkr_idcard_v2`, `mkr_login_lock_v2`.
- Fonts self-hosted (`public/fonts/*.woff2`, `public/fonts.css`) — no Google CDN.
- Icons generated by `tools/mkicon.py` (pure stdlib) → `public/icons/*.png`.
- Test = `npm test` → `tests/smoke.mjs` (jsdom, bundles src/main.tsx via esbuild,
  48 asserts). Build = `npm run build` (tsc --noEmit && vite build).
- ⚠️ Do NOT use `React.lazy` route splitting — the jsdom smoke test bundles to a
  single IIFE, so dynamic `import()` breaks the test. Use manualChunks instead.
- ⚠️ After switching Pages build_type, a QUEUED legacy "pages build and deployment"
  run can overwrite the site with the repo root — re-dispatch deploy.yml if live
  html references `/src/main.tsx`.
